📖 コンペ＆ゲーム ルール説明

1. 基本ルール & ハンディキャップ

幹事画面でプレイヤー個別に設定された**「適用ホール」**において、グロス打数にハンディ値（-3〜+1）を加減算した**「ネット打数」**を算出します。
★ スコアP、ラスベガスの判定、前ホール順位はすべてネット打数を基準に行われます。

2. スコアポイント (規定打数 Par 比)

  • イーグル以上: +3P
  • バーディ: +2P
  • パー: +1P
  • ボギー以上: 0P

3. ゲームボーナス ＆ ペナルティ

  • チップイン: +2P
  • ワンパット: +1P
  • サオイチ: +1P (ワンパット自動連動で 実質+2P)
  • 砂イチ: +1P (バンカー-1P、ワンパット+1P連動で 実質+1P)
  • ペナルティ (OB / 池 / バンカー / 3パット以上): 各 -1P

4. ラスベガス (たすき掛けペア戦)

・1Hはランダム5組。2H以降は前ホールのネット実績順位でたすき掛けペア編成（1位&10位、2位&9位、3位&8位、4位&7位、5位&6位）。
・前ホールの10名全員が完了するまでペア相手・チームは完全非公開。
・ペア2名のネット打数を小さい順に並べた2桁数字で競います。
・配当: 1位 3P / 2位 2P / 3位 1P / 4・5位 0P（同点は均等分配）。

5. タイトルP (ニアピン・ドラコン)

・基本 10P。該当者なしは次対象ホールへ持ち越し（最大 20P）。
・個人累計上限: 1人最大20Pまで。
・累計20Pに達している人が獲得した場合、付与は0Pとなり**「他者の獲得を阻止するブロッカー」**として機能します（持ち越しも消滅）。
